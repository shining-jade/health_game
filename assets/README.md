# Published Game Assets

This is the runtime asset folder for:

```text
health_game_publish/index.html
```

When adding or replacing images used by the main playable game, put the final files here.

Important sibling folder:

```text
health_game_publish/drink_menu_previews/
```

That folder is also referenced directly by `health_game_publish/index.html`.

Do not confuse this folder with root `assets/`, which is treated as working/source material.
