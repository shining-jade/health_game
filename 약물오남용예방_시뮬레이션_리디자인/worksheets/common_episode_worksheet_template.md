# 에피소드 공통 활동지 템플릿

## 활동지 목적

활동지는 게임 속 추리 경험을 학습으로 고정하는 장치다. 정답 맞히기보다 관찰, 근거 작성, 안전한 대응 선택을 강화한다.

## 기본 구성

### 1. 사건명

오늘 조사한 사건의 이름을 적는다.

### 2. 핵심 질문

이번 사건에서 가장 중요하게 해결해야 할 질문을 적는다.

### 3. 관찰한 증상

친구에게 나타난 몸 상태, 말투, 행동 변화를 사실 중심으로 적는다.

### 4. 단서 정리

확인한 단서를 적고, 단서가 의미하는 바를 구분한다.

| 단서 | 확인한 사실 | 내가 생각한 의미 |
| --- | --- | --- |
|  |  |  |
|  |  |  |
|  |  |  |

### 5. 처음 가설

처음에는 원인이 무엇이라고 생각했는지 적는다.

### 6. 생각이 바뀐 이유

새로운 단서를 보고 생각이 어떻게 바뀌었는지 적는다.

### 7. 실제 원인 조합

사건의 원인이 한 가지인지, 여러 가지가 겹친 것인지 정리한다.

### 8. 안전한 대응

이 상황에서 친구를 돕기 위해 할 수 있는 안전한 행동을 적는다.

### 9. 오늘 배운 점

약물, 카페인, 복약, 건강 신호에 대해 새롭게 배운 점을 적는다.

### 10. 내가 사용한 역량

오늘 가장 많이 사용한 역량에 표시하고 이유를 적는다.

- 관찰력
- 분석력
- 공감력
- 신중함
- 대응력
- 건강문해력

## 운영 방식

- 게임 중 작성: 증상, 단서, 첫 가설
- 게임 후 작성: 실제 원인, 대응, 배운 점, 자기평가
