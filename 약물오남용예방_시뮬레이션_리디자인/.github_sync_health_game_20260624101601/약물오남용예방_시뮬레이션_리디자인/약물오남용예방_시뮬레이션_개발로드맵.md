# 약물오남용예방 시뮬레이션 개발 구현 로드맵

## 1. 프로젝트 방향

본 프로젝트는 기존의 **자기관리형 육성 시뮬레이션** 구조를 바탕으로,  
**친구 사건형 추리 에피소드**를 결합한 **옴니버스형 보건 추리 시뮬레이션**으로 확장한다.

핵심 목표는 다음과 같다.

- 학생이 주변 인물의 건강 이상 상황을 관찰하고
- 단서를 수집하며
- 원인을 추론하고
- 안전한 대응을 학습하도록 하는 것

---

## 2. 전체 구조 개요

### 2.1 메인 구조
- **첫 화면:** 에피소드 선택
- **사건 진행:** 장면 기반 추리/조사
- **조사 장면:** 핫스팟 클릭형 단서 수집
- **정리 장면:** NPC 대사, 보건교사 해석, 감정 회수
- **결과 화면:** 학습 요약, 메모 정리, 출력/저장

### 2.2 화면 상태
- `episode-select`
- `scene-view`
- `result-view`

---

## 3. 에피소드 구성 방향

### 추천 총 에피소드 수
**6편**

### 추천 에피소드
1. **떨리는 손의 이유**  
   - 시험기간 카페인 사건
   - 수면 부족 + 약 복용 + 반복 카페인 섭취

2. **한 잔인데 왜 다르지?**  
   - 에너지음료 / 캔커피 / 카페 커피
   - 종류와 용량에 따른 카페인 차이

3. **먹었나, 안 먹었나**  
   - 중복 복용 / 복용 시간 혼동

4. **같은 약 같아 보여도**  
   - 가족 약 / 타인 처방약 복용

5. **SNS 속 공부 꿀팁의 함정**  
   - 온라인 정보 판별 / 디지털 리터러시

6. **괜찮을 줄 알았어**  
   - 약 복용 후 주의사항 미확인
   - 졸음, 집중 저하, 설명서 읽기

## 8. 조사 장면 설계

### 8.1 구조
조사 장면은 선택지 버튼형이 아니라 **이미지 클릭형 핫스팟 구조**를 사용한다.

### 목표
- 화면 점유를 줄임
- 조사/추리 몰입감 강화
- 단서 수집을 직접 체험하게 함

---

### 8.2 조사 장면 흐름
1. 조사 이미지 표시
2. 핫스팟 클릭
3. 단서 상세 카드 표시
4. 단서 획득
5. 메모/단서함 반영
6. 핵심 단서 일정 수 확보
7. 다음 분석 단계로 이동

---

### 8.3 조사 장면 조건
- 핵심 단서 3개 중
- **2개 이상 확보 시**
- 다음 장면으로 진행 가능

#### 사건 1 기준 핵심 단서
- 감기약 봉투
- 메모지
- 음료 캔

#### 보조 단서
- 필통
- 물병

---

### 8.4 조사 장면 시각 피드백
단서를 찾으면:
- 점선 → 초록 실선
- 체크 배지 표시
- 라벨 강조
- 진행도 갱신

---

### 8.5 조사 완료 후 전환
핵심 단서 확보 후 `다음 분석` 버튼을 누르면  
짧은 전환 오버레이를 거쳐 다음 장면으로 넘어간다.

예:
- `핵심 단서를 확보했습니다`
- `찾은 단서를 바탕으로 상황을 정리합니다...`

## 20. 최종 개발 목표

이 프로젝트의 최종 목표는 단순히 사건을 푸는 것이 아니라:

- 학생이 건강 문제를 **관찰하고**
- 정보를 **근거 중심으로 해석하며**
- 더 안전한 행동을 **스스로 정리할 수 있게** 하는 것

이다.

즉,  
**게임은 몰입을 만들고, 메모장과 활동지는 사고를 정리하며, 결과 화면은 학습을 회고하게 만드는 구조**로 완성한다.

# 한 줄 요약

이 로드맵은 **옴니버스형 보건 추리 시뮬레이션**을 기준으로, 에피소드 선택 → 장면 진행 → 핫스팟 조사 → 메모/단서/활동지 연계 → 결과 출력/저장까지의 전체 구현 흐름을 정리한 문서다.
