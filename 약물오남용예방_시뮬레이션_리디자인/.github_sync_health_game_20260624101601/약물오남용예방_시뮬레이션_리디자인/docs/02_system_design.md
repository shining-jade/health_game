# 시스템 설계 초안

## 1. 상태창 재설계

친구 사건형에서는 기존의 "내 몸 상태" 중심 상태창만으로는 서사적 의미가 약하다. 상태창은 플레이어의 문제해결 역량과 사건 개입 상태를 보여주는 방향으로 재설계한다.

### 핵심 지표

- 관찰력: 증상, 말투, 행동, 사물의 이상함을 포착하는 능력
- 판단력: 단서를 연결하고 성급한 결론을 피하는 능력
- 공감도: 친구/NPC의 감정과 숨긴 이유를 이해하는 능력
- 대응력: 적절한 질문과 개입을 선택하는 능력
- 건강문해력: 약물, 카페인, 복약, 디지털 정보에 대한 이해도
- 신뢰도: NPC들이 플레이어를 얼마나 신뢰하는지 나타내는 지표

### 표시 방식

- 숫자보다 아이콘과 막대형 UI 우선
- 세부 수치보다 직관적 이해 중심
- 에피소드 종료 후 육각형 성장 시각화와 연동

## 2. 사건 패널

사건 패널은 현재 사건의 진행 상황을 보여주는 별도 UI다.

### 포함 요소

- 현재 사건명
- 관찰된 이상 징후
- 확인된 사실
- 아직 불확실한 점
- 조사 진행도
- 확보 단서 수

### 역할

- 플레이어가 지금 무엇을 추리하고 있는지 명확히 보여준다.
- 사건 몰입도를 강화한다.
- 모바일에서는 축약형, PC에서는 확장형으로 운영한다.

## 3. 아이템창

아이템창은 전투 아이템이 아니라 **증거 보관함** 역할을 한다.

### 아이템 분류

- 물리 단서: 약 봉투, 영수증, 음료 캔, 메모지, 복용 수첩
- 디지털 단서: 채팅 캡처, SNS 게시물, 검색 기록, 알람 기록
- 관찰 기록: 표정, 행동 변화, 진술의 모순
- 참고 정보: 카페인 권장량, 복약 안내, 보건실 팁

### 기능

- 확대 보기
- 메모장으로 보내기
- 단서 비교하기
- 중요 단서 표시하기

## 4. 메모장

메모장은 추리형 진행의 핵심 도구이며, 디지털 게임과 오프라인 활동지를 연결하는 중심 장치다.

### 탭 구성

- 관찰한 사실
- 의심되는 점
- 핵심 질문
- 대응 계획
- 배운 점

### 설계 원칙

- 사실과 추측을 구분할 수 있어야 한다.
- 추리의 근거를 자기 언어로 정리하게 한다.
- 활동지와 동일한 구조를 가져야 한다.

## 5. 육각형 성장 시스템

육각형은 최종 목표가 아니라 플레이어의 건강 추리 역량을 시각화하는 장치다.

### 추천 6축

- 관찰력
- 분석력
- 공감력
- 신중함
- 대응력
- 건강문해력

### 활용 원칙

- "모두 채우기" 자체가 최종 목표가 되지 않게 한다.
- 에피소드를 통해 어떤 역량이 성장했는지 보여준다.
- 활동지의 자기평가 문항과 연결한다.

## 6. 에피소드 종료 화면

에피소드 종료는 단순 정답 확인이 아니라 **사건 회고, 학습 정리, 성장 피드백** 구조로 설계한다.

### 1단계: 사건 해결 결과

- 원인 요약
- 핵심 단서
- 놓친 단서

### 2단계: 학습 정리

- 위험 신호
- 잘못 알기 쉬운 오해
- 안전한 행동 원칙

### 3단계: 성장 피드백

- 어떤 역량이 강화되었는지
- 육각형 성장 시각화
- 다음 에피소드에 연결되는 태도
