# 프로젝트 방향 정리

## 1. 방향 전환 요약

기존 콘텐츠는 플레이어 자신의 생활 습관, 카페인 섭취, 약물 오남용 위험을 관리하는 육성 시뮬레이션에 가까웠다.

리디자인에서는 여기에 **친구 사건형 추리 에피소드**를 결합한다. 플레이어는 직접 오남용의 당사자가 되기보다, 주변 학생의 이상 징후를 발견하고 원인을 추론하며 안전한 대응을 선택한다.

## 2. 핵심 게임 구조

- 육성 시뮬레이션: 일정, 선택, 상태 관리, 생활 습관 형성
- 추리 에피소드: 친구 또는 NPC의 이상 상황 원인 분석
- 교육 정리: 사건의 원인, 위험 신호, 안전한 대응 학습
- 활동지 연계: 오프라인에서 근거 작성 및 사고 정리

## 3. 친구 사건형의 의미

친구 사건형은 다음 행동을 중심으로 진행된다.

- 주변 학생의 증상 관찰
- 진술 비교
- 단서 수집
- 원인 재구성
- 적절한 대응 선택

이 방식은 추리적 몰입을 강화하고, 보건교육 상황에서 토론형 수업으로 확장하기 쉽다.

## 4. 최종 교육 목표

최종 목표는 단순히 사건의 정답을 맞히는 것이 아니다.

- 건강한 판단을 훈련한다.
- 근거를 들어 설명할 수 있게 한다.
- 실생활에서 더 안전한 선택을 하도록 돕는다.
