# 6편 옴니버스 구성안 및 에피소드 선택 UI

## 1. 결론

현재까지 논의된 소재 기준으로는 **6편 구성**이 가장 자연스럽다. 시작 화면은 **에피소드 선택형 옴니버스 구조**로 설계한다.

## 2. 추천 구조

- 사건은 독립적
- 같은 학교와 보건실을 공유
- 보건샘과 일부 학생이 반복 등장
- 육각형 역량은 누적 성장
- 활동지는 에피소드별로 1:1 대응

## 3. 6개 에피소드 구성

| 에피소드 | 제목 | 주제 | 역할 |
| --- | --- | --- | --- |
| EP01 | 떨리는 손의 이유 | 시험기간 반복 카페인 섭취 + 약 복용 + 수면 부족 | 첫 사건, 추리 시스템 학습 |
| EP02 | 한 잔인데 왜 다르지? | 음료 종류, 용량, 카페인량 차이 | 표시 읽기, 비교 추리 |
| EP03 | 먹었나, 안 먹었나 | 중복 복용, 복용 시간 혼동 | 기록과 복약 습관 |
| EP04 | 같은 약 같아 보여도 | 가족 약/타인 처방약 복용 | 처방약 공유 금지 |
| EP05 | SNS 속 공부 꿀팁의 함정 | 검증되지 않은 온라인 정보 | 디지털 리터러시 |
| EP06 | 괜찮을 줄 알았어 | 약 복용 후 주의사항 미확인 | 설명서 읽기, 안전 판단 |

## 4. 시작 화면 컨셉

추천 제목:

- 보건 미스터리 파일
- 사건 파일 선택
- 건강 추리 아카이브
- 보건실 사건기록
- 오늘의 사건 선택

현재 프로토타입에는 **보건 미스터리 파일**을 적용한다.

## 5. 에피소드 카드 구성

카드에 표시할 정보:

- 에피소드 번호
- 사건 제목
- 핵심 키워드
- 난이도
- 예상 시간
- 사용 역량
- 활동지 여부
- 진행 상태

## 6. 에피소드 선택형 장점

- 수업 운영이 쉬움
- 반복 플레이가 쉬움
- 활동지 매칭이 쉬움
- 옴니버스 구조와 잘 맞음
- 교사가 원하는 주제만 골라 진행 가능

## 7. 데이터 파일

에피소드 선택 화면용 데이터는 다음 파일에 둔다.

- `assets/data/episodes.json`

현재 `index.html`에는 정적 카드로 먼저 반영했고, 이후 이 JSON을 읽어서 자동 렌더링할 수 있다.
