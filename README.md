# 일반의약품 시뮬레이션 배포본

GitHub Pages 기준 실행 파일은 `index.html`입니다.

## 작업 기준

- 게임 실행: `index.html`
- 이미지/캐릭터/카드 에셋: `assets/`
- 음료 메뉴 이미지: `drink_menu_previews/`
- GitHub Pages 유지 파일: `.nojekyll`

예전 HTML 버전과 에디터 복사본은 루트 폴더의 `_archive/github_publish_old_files/`에 보관했습니다. 이 저장소에서는 `index.html`을 기준으로 수정하면 됩니다.
